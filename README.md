# GitHub Repository User Guide

A beginner-friendly technical documentation project explaining how to create and manage a GitHub repository. This guide includes step-by-step instructions, screenshots, and troubleshooting tips.

## Getting Started

Read the full guide: [Getting Started](getting-started.md).

## Overview

This guide explains how to create a GitHub repository, add files, make changes, and publish those changes to GitHub.

It is designed for beginners who have little or no previous experience using GitHub.

## Prerequisites

Before you begin, you will need:

- A GitHub account
- An internet connection
- A web browser
- A basic understanding of files and folders

## What You Will Learn

By the end of this guide, you will know how to:

- Create a GitHub repository
- Add files to a repository
- Create and edit a README file
- Commit changes
- View your repository on GitHub

## Creating Your First Repository

### Step 1: Sign in to GitHub

Sign in to your GitHub account.

### Step 2: Create a new repository

1. Select the **+** icon in the upper-right corner of GitHub.
2. Select **New repository**.
3. Enter a name for your repository.
4. Add a description.
5. Select **Public** if you want others to be able to view your repository.
6. Select **Add a README file**.
7. Select **Create repository**.

### Step 3: Add a file

After creating your repository, you can add files by selecting **Add file** and then selecting **Create new file** or **Upload files**.

### Step 4: Commit your changes

After making changes to your repository, add a short description of the changes and select **Commit changes**.

A commit records a change made to the repository.

## Troubleshooting

### I cannot find my repository

Make sure you are signed in to the correct GitHub account. You can view your repositories by selecting your profile picture and choosing **Your repositories**.

## Conclusion

You have now created a GitHub repository and learned the basic steps for adding files and recording changes.
